# markIT Frontend

This folder contains the Next.js frontend for markIT, a full-stack notes and task-list productivity app.

For the complete project overview, setup instructions, backend details, and deployment notes, see the root README:

```text
../README.md
```

For backend endpoint documentation, see:

```text
../API_DOCUMENTATION.md
```

## Quick Start

```bash
npm install
npm run dev
```

Open:

```text
http://localhost:3000
```

## Environment

Create `.env.local` to override the backend URL:

```env
NEXT_PUBLIC_API_BASE_URL=https://notes-app-1-88gd.onrender.com
```

## Scripts

```bash
npm run dev
npm run build
npm run start
npm run lint
```
